# Daily workflow

1. Pull the day's launches from a PH tracker; verify date, tagline, upvotes.
2. Run `prompts/assess.md` per launch with your LLM; paste output into your private data file.
3. Open the app: FIRE high scores, KILL the rest.
4. Send the connection note on LinkedIn; mark status pending.
5. Update to connected / replied as it happens. Keep the streak.
